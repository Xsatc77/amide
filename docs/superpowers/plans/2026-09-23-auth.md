# Legal Notice, Accounts & 2FA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Legal notice gate, private user accounts with open registration, optional TOTP 2FA, 10-minute session timeout.

**Architecture:** `app/auth/` holds pure rules (`passwords.py`, `totp.py`) and session handling (`sessions.py`, clock injectable). A middleware in `app/auth/gate.py` resolves the session cookie on every request and redirects to the right step. `app/routers/auth.py` serves the screens. Inventory/protocol routers filter by `request.state.user`. Migration `0006` adds `users`, `sessions`, and `owner_id` columns.

**Tech Stack:** FastAPI/Starlette middleware, SQLAlchemy, Alembic, argon2-cffi, pyotp, segno, Jinja2, vanilla JS.

**Spec:** `docs/superpowers/specs/2026-09-23-auth-design.md`

## Global Constraints

- Password min length from `config.PASSWORD_MIN_LENGTH` (env `AMIDE_PASSWORD_MIN_LENGTH`, default 4).
- Session idle limit `config.SESSION_IDLE_MINUTES` = 10; lockout 5 failures / 15 minutes.
- Cookie `amide_session`: HttpOnly, SameSite=Lax, Secure when request scheme is https.
- No backup codes. No email.
- Built in the worktree `C:\tmp\amide-auth` (branch `feature/auth`), never in the owner's running folder.

## Review Focus

1. User B requests `/inventory/{A's id}/coa`, `/protocols/{A's id}/edit`, `/api/protocols/{A's id}` → 404, never A's data. (Task 3 `test_other_users_data_is_invisible`)
2. Session idle 10:01 minutes → next request lands on the notice, not a page. (Task 1/2 `test_session_expires_after_idle_limit`)
3. Registering "Chris" when "chris" exists → error, no second account. (Task 2 `test_register_username_case_insensitive`)
4. Correct password on a locked account → still refused until the lock passes. (Task 2 `test_lockout`)
5. POST from another origin (Origin header mismatch) → 403. (Task 2 `test_cross_origin_post_rejected`)
