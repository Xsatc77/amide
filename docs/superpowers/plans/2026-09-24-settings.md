# Settings Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `/settings` hub (User, Display, Integrations, Admin-if-admin sections) reached from the username menu, replacing today's direct "Two-factor authentication" / "Backup & restore" menu links with one "Settings" link.

**Architecture:** Pure validation lives in `app/settings/rules.py` (email/timezone format) and reuses `app/auth/passwords.py` (username/password rules) — nothing new to test there. `app/routers/settings.py` is the single router for every section's routes. Colorways are CSS-only: a `data-theme` attribute on `<html>`, set server-side from `User.colorway`, with one `:root[data-theme="..."]` block per palette in `app/static/css/app.css`. The Admin section's user table and the CLI's `list` command share one query helper (`app.users.user_rows`) so they can never drift apart.

**Tech Stack:** FastAPI, SQLAlchemy, Alembic, Jinja2, vanilla JS, pytest, `zoneinfo` (stdlib).

**Spec:** `docs/superpowers/specs/2026-09-24-settings-design.md`

## Global Constraints

- Sharing (share inventory / share personal data) is **not** part of this plan — deferred, per the spec.
- Timezone is **display-only** in this pass: it formats the Admin table's "last login" column only. It must not touch Protocols' or Calendar's "today" logic.
- Every `/settings/admin/*` route re-checks `request.state.user.is_admin` itself (never trust that the template hid the link) and returns 404 — not 403 — for a non-admin caller, matching how every other owned-resource route in this app already treats "not yours."
- High Contrast's CSS uses pure `#000000`/`#ffffff` only — no soft/tinted variants, no color-coded danger (a `--danger` value still exists for the variable to resolve, but it equals the same black/white pair, since a strict two-color palette can't carry a third meaning through color alone).
- Deleting a user is refused when the target is the caller themselves (there is no promote-to-admin flow, so losing the only admin would be unrecoverable).

## Review Focus

1. Changing your own password ends every *other* session for your account but not the one you're using right now. (Task 2, `test_password_change_ends_other_sessions_not_this_one`)
2. A non-admin who guesses an admin URL (e.g. `/settings/admin/users/1/delete`) gets 404, not a permission error page that confirms the route exists. (Task 4, `test_admin_routes_404_for_non_admin`)
3. Deleting a user who owns inventory (with a COA file on disk) and protocols removes all of it — not just the `User` row — and the COA file is actually unlinked from disk. (Task 4, `test_delete_user_cascades_inventory_coa_and_protocols`)
4. The delete-user confirmation is enforced server-side: posting the delete route with the wrong typed username does nothing, even if a browser bypassed the JS. (Task 4, `test_delete_user_requires_exact_username_match_server_side`)
5. An admin cannot delete their own account through this UI. (Task 4, `test_admin_cannot_delete_self`)

# app/settings/rules.py
"""Pure validation for account-settings fields that aren't already covered by app.auth.passwords."""

import re
import zoneinfo

TIMEZONES: list[str] = sorted(zoneinfo.available_timezones())
_TIMEZONE_SET = set(TIMEZONES)

_EMAIL = re.compile(r"^[^@\s]+@[^@\s]+\.[^@\s]+$")


def email_error(value: str) -> str | None:
    """None for a blank value (email is optional) or a plausible address; otherwise a message."""
    value = (value or "").strip()
    if not value:
        return None
    if not _EMAIL.match(value):
        return "Enter a valid email address."
    return None


def timezone_error(value: str) -> str | None:
    """None for blank ("System") or a real IANA zone name; otherwise a message."""
    value = (value or "").strip()
    if not value:
        return None
    if value not in _TIMEZONE_SET:
        return "Pick a timezone from the list."
    return None
```

# app/routers/settings.py
"""The /settings hub: User, Display, Integrations, Admin-if-admin sections."""

from fastapi import APIRouter, Depends, Request
from fastapi.responses import RedirectResponse
from sqlalchemy import select
from sqlalchemy.orm import Session

from app.auth import passwords, sessions
from app.auth.deps import current_user_id
from app.db import get_session
from app.models import Colorway, User
from app.settings.rules import TIMEZONES, email_error, timezone_error
from app.templating import templates

router = APIRouter()


def _me(session: Session, uid: int) -> User:
    return session.get(User, uid)


def _render(request: Request, session: Session, *, errors: dict | None = None, status_code: int = 200):
    me = _me(session, request.state.user.id)
    return templates.TemplateResponse(request, "settings/settings.html", {
        "me": me, "errors": errors or {}, "timezones": TIMEZONES, "colorways": list(Colorway),
    }, status_code=status_code)


@router.get("/settings")
def settings_page(request: Request, session: Session = Depends(get_session)):
    return _render(request, session)


@router.post("/settings/username")
async def change_username(request: Request, session: Session = Depends(get_session),
                          uid: int = Depends(current_user_id)):
    form = await request.form()
    new_name = str(form.get("username", "")).strip()
    current_password = str(form.get("current_password", ""))
    me = _me(session, uid)
    errors: dict[str, str] = {}

    if not passwords.verify_password(me.password_hash, current_password):
        errors["current_password"] = "Current password is incorrect."
    if err := passwords.username_error(new_name):
        errors["username"] = err
    elif not errors:
        key = passwords.username_key(new_name)
        clash = session.scalar(select(User).where(User.username_key == key, User.id != me.id))
        if clash:
            errors["username"] = "That username is already taken."

    if errors:
        return _render(request, session, errors=errors, status_code=422)

    me.username, me.username_key = new_name, passwords.username_key(new_name)
    session.commit()
    return RedirectResponse("/settings", status_code=303)


@router.post("/settings/password")
async def change_password(request: Request, session: Session = Depends(get_session),
                          uid: int = Depends(current_user_id)):
    form = await request.form()
    current_password = str(form.get("current_password", ""))
    new_password = str(form.get("new_password", ""))
    confirm = str(form.get("confirm", ""))
    me = _me(session, uid)

    errors: dict[str, str] = {}
    if not passwords.verify_password(me.password_hash, current_password):
        errors["current_password"] = "Current password is incorrect."
    if problems := passwords.password_errors(new_password, confirm):
        errors["new_password"] = " ".join(problems)
    if errors:
        return _render(request, session, errors=errors, status_code=422)

    me.password_hash = passwords.hash_password(new_password)
    session.commit()
    sessions.end_other_sessions(session, me.id, request.state.session_id)
    return RedirectResponse("/settings", status_code=303)


@router.post("/settings/timezone")
async def change_timezone(request: Request, session: Session = Depends(get_session),
                          uid: int = Depends(current_user_id)):
    form = await request.form()
    mode = str(form.get("mode", "system"))
    tz = str(form.get("timezone", "")).strip() if mode == "manual" else ""

    if err := timezone_error(tz):
        return _render(request, session, errors={"timezone": err}, status_code=422)

    _me(session, uid).timezone = tz or None
    session.commit()
    return RedirectResponse("/settings", status_code=303)


@router.post("/settings/email")
async def change_email(request: Request, session: Session = Depends(get_session),
                       uid: int = Depends(current_user_id)):
    form = await request.form()
    value = str(form.get("email", "")).strip()

    if err := email_error(value):
        return _render(request, session, errors={"email": err}, status_code=422)

    _me(session, uid).email = value or None
    session.commit()
    return RedirectResponse("/settings", status_code=303)
```

@router.post("/settings/display")
async def change_display(request: Request, session: Session = Depends(get_session),
                         uid: int = Depends(current_user_id)):
    form = await request.form()
    value = str(form.get("colorway", "")).strip()

    colorway = None
    if value:
        try:
            colorway = Colorway(value)
        except ValueError:
            return _render(request, session, errors={"colorway": "Pick a colorway from the list."},
                          status_code=422)

    _me(session, uid).colorway = colorway
    session.commit()
    return RedirectResponse("/settings", status_code=303)

@router.post("/settings/admin/users/new")
async def admin_add_user(request: Request, session: Session = Depends(get_session)):
    _require_admin(request)
    form = await request.form()
    new_name = str(form.get("username", "")).strip()
    new_password = str(form.get("password", ""))
    confirm = str(form.get("confirm", ""))

    errors: dict[str, str] = {}
    if err := passwords.username_error(new_name):
        errors["new_user_username"] = err
    elif session.scalar(select(User).where(User.username_key == passwords.username_key(new_name))):
        errors["new_user_username"] = "That username is already taken."
    if problems := passwords.password_errors(new_password, confirm):
        errors["new_user_password"] = " ".join(problems)
    if errors:
        return _render(request, session, errors=errors, status_code=422)

    session.add(User(username=new_name, username_key=passwords.username_key(new_name),
                     password_hash=passwords.hash_password(new_password)))
    session.commit()
    return RedirectResponse("/settings#admin", status_code=303)


def _target_user(request: Request, session: Session, user_id: int) -> User:
    _require_admin(request)
    user = session.get(User, user_id)
    if user is None:
        from fastapi import HTTPException
        raise HTTPException(404)
    return user


@router.post("/settings/admin/users/{user_id}/reset-password")
async def admin_reset_password(user_id: int, request: Request, session: Session = Depends(get_session)):
    target = _target_user(request, session, user_id)
    form = await request.form()
    new_password, confirm = str(form.get("password", "")), str(form.get("confirm", ""))

    if problems := passwords.password_errors(new_password, confirm):
        return _render(request, session, errors={"reset_password": " ".join(problems)}, status_code=422)

    target.password_hash = passwords.hash_password(new_password)
    sessions.clear_failures(target)
    session.commit()
    sessions.end_all_sessions(session, target.id)
    return RedirectResponse("/settings#admin", status_code=303)


@router.post("/settings/admin/users/{user_id}/remove-2fa")
async def admin_remove_2fa(user_id: int, request: Request, session: Session = Depends(get_session)):
    target = _target_user(request, session, user_id)
    target.totp_enabled, target.totp_secret, target.totp_last_step = False, None, None
    session.commit()
    return RedirectResponse("/settings#admin", status_code=303)


@router.post("/settings/admin/users/{user_id}/delete")
async def admin_delete_user(user_id: int, request: Request, session: Session = Depends(get_session)):
    target = _target_user(request, session, user_id)
    if target.id == request.state.user.id:
        return _render(request, session, errors={"delete": "You can't delete your own account."},
                      status_code=422)

    form = await request.form()
    if str(form.get("username", "")) != target.username:
        return _render(request, session, errors={"delete": "Typed username didn't match."}, status_code=422)

    for item in session.scalars(select(InventoryItem).where(InventoryItem.owner_id == target.id)):
        uploads.delete_coa(item.coa_filename)
        session.delete(item)
    for protocol in session.scalars(select(Protocol).where(Protocol.owner_id == target.id)):
        session.delete(protocol)
    for vendor in session.scalars(select(Vendor).where(Vendor.owner_id == target.id)):
        session.delete(vendor)
    session.delete(target)
    session.commit()
    return RedirectResponse("/settings#admin", status_code=303)

// Settings page behaviour: the two-step, effortful delete-user confirmation.
(() => {
  const firstDialog = document.getElementById("delete-user-dialog");
  const confirmDialog = document.getElementById("delete-user-confirm-dialog");
  if (!firstDialog) return;  // non-admin: no admin section on the page

  const form = document.getElementById("delete-user-form");
  const input = document.getElementById("delete-confirm-input");
  const submitBtn = document.getElementById("delete-confirm-submit");
  let targetUsername = "";

  document.addEventListener("click", (e) => {
    const btn = e.target.closest('[data-action="delete-user"]');
    if (btn) {
      targetUsername = btn.dataset.username;
      form.action = btn.dataset.url;
      document.getElementById("del-username-1").textContent = targetUsername;
      document.getElementById("del-username-2").textContent = targetUsername;
      firstDialog.showModal();
    }
    if (e.target.closest('[data-action="cancel-delete"]')) {
      firstDialog.close();
      confirmDialog.close();
    }
    if (e.target.closest('[data-action="continue-delete"]')) {
      firstDialog.close();
      input.value = "";
      submitBtn.disabled = true;
      confirmDialog.showModal();
    }
  });

  input.addEventListener("input", () => {
    submitBtn.disabled = input.value !== targetUsername;
  });
})();
