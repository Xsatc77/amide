# Labs & Medical Results (Phase 6, part 3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** build the Labs feature described in the spec — bulk entry of blood-marker results per
panel/draw (each result carrying its own user-entered reference range), an optional PDF/image
report attachment per panel, per-marker trend charts with a range selector, and a query-time view
of which protocol(s) were active around each draw date. Completes the last placeholder tab on the
Weight & Measurements page.

**Architecture:** a new `LabMarker` enum + `LabPanel`/`LabResult` tables plus report-file-upload
helpers reusing the existing COA upload convention (Task 1); a new `app/routers/labs.py` module
(sharing-scoped queries, the bulk-entry form, the Labs tab's list view) wired into the existing
tabbed Weight & Measurements page, kept separate from `measurements.py` for the same file-focus
reason Journal's own router is separate (Task 2); per-marker SVG trend charts with the same
range-selector pattern already established (Task 3); the query-time protocol/dose overlay added
last (Task 4).

**Tech Stack:** FastAPI + SQLAlchemy 2.0 + Alembic (SQLite) + Jinja2 + vanilla JS (no new
dependencies — continuing this app's existing conventions).

**Spec:** `docs/superpowers/specs/2026-09-28-labs-design.md`

## Global Constraints

- Every reference range is user-entered per result — no built-in "standard" range per marker.
- One optional file per panel (PDF or image) — no multi-file galleries, no Word-document support
  (unlike vendor price lists — a lab report is always a PDF or a photo/scan of one).
- No automatic PDF parsing/OCR — typed entry only.
- Sharing follows the existing `ShareCategory.PERSONAL_DATA` category, same as Weight &
  Measurements and Journal.
- This session's prior features have repeatedly found the same three recurring test-fixture bugs:
  (1) inserting a seeded-name row unconditionally collides with a real seeded row under a unique
  constraint; (2) an unfiltered `select(User.id)` picks the wrong user under full-suite test-order
  pollution — pin via `User.username_key == "tester"`; (3) a POSIX-only `%-d` strftime flag crashes
  on Windows — use `{{ x.strftime('%b') }} {{ x.day }}` instead. Watch for all three.

## Review Focus

(Carried verbatim from the spec's own Review Focus section — each gets its test in the task that
owns the relevant code.)

1. A result row's "out of range" flag must only ever be computed from that SPECIFIC result's own
   `range_low`/`range_high` — never a different marker's range, and never shown at all when either
   bound is missing.
2. `marker_other` must be required when (and only required when) `marker == LabMarker.OTHER`.
3. Trend charts must never mix a sharing partner's results into the signed-in user's own chart
   series.
4. The uploaded-report validation must reject a disguised file the same way COA uploads already do
   (content-sniffed, not just filename/extension trust).
5. The "what was active" protocol lookup must scope to each panel's own `drawn_at` date when
   browsing multiple past panels in the list view — not always "today's" active protocols.

    owner_id: Mapped[int] = mapped_column(ForeignKey("users.id", ondelete="CASCADE"), index=True)
    drawn_at: Mapped[date] = mapped_column(Date, index=True)
    notes: Mapped[str | None] = mapped_column(Text)
    report_filename: Mapped[str | None] = mapped_column(String(120))
    created_at: Mapped[datetime] = mapped_column(DateTime(timezone=True), default=utcnow)

    results: Mapped[list["LabResult"]] = relationship(
        back_populates="panel", cascade="all, delete-orphan")


class LabResult(Base):
    __tablename__ = "lab_results"
    __table_args__ = (

```python
async def save_lab_report(upload: UploadFile) -> str:
    """Validate and store an uploaded lab report. Returns the stored filename."""
    ext = Path(upload.filename or "").suffix.lower()
    if ext not in ALLOWED_TYPES:
        raise UploadError("Lab report must be a photo (JPG, PNG, WEBP, HEIC) or a PDF.")

    data = await upload.read(config.MAX_UPLOAD_BYTES + 1)
    if len(data) > config.MAX_UPLOAD_BYTES:
        raise UploadError(f"Lab report is larger than {config.MAX_UPLOAD_BYTES // (1024 * 1024)} MB.")
    if not _sniff_ok(ext, data[:16]):
        raise UploadError("Lab report file contents don't match its file type.")

    config.ensure_dirs()
    filename = f"{uuid.uuid4().hex}{ext}"
    (config.LAB_REPORT_DIR / filename).write_bytes(data)
    return filename


def lab_report_path(filename: str) -> Path:
    return config.LAB_REPORT_DIR / filename


def delete_lab_report(filename: str | None) -> None:
    if filename:
        lab_report_path(filename).unlink(missing_ok=True)
```
