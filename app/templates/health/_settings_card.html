2. Set up the phone app

  1. In Health Auto Export, create a new automation of type REST API.
  2. For the URL, use this address: {{ health.ingest_url }}
  3. Add a header. Its name is Authorization and its value is Bearer, a space, then your token. {% if health.header_line %}The whole line: {{ health.header_line }} {% else %}The full line is only shown right after you create a token; create a new one if you lost it.{% endif %}
  4. Set Data Type to Health Metrics first. Later, add a second automation for Workouts, and others as you like.
  5. Set Export Format to JSON and Export Version to Version 2.
  6. Set Date Range to Since Last Sync.
  7. Turn Summarize Data on and set Time Grouping to Hours, so a year of steps is not a million rows. For the very first export, pick Previous 7 Days, or run a wider range by hand with Manual Export.
  8. Turn Batch Requests on.
  9. Set Sync Cadence to every hour.
  10. Tap Manual Export to test. The status below should change within a minute.

If Amide sits behind a reverse proxy: allow request bodies large enough for the first export (Amide itself accepts up to {{ health.max_mb }} MB a post; whoever runs Amide can raise that with the one setting AMIDE_HEALTH_MAX_MB), and if anything asks for a separate login in front of Amide, exempt the path /api/ingest/ from it, or the phone will be turned away.
